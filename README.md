# 🚀 Prozzy Webpage

Uma landing page moderna e responsiva desenvolvida para a plataforma Prozzy, incluindo interface de login e design focado em experiência do usuário (UX).

> **Status:** ✅ Concluído

## 🖥️ Sobre o Projeto
Este projeto faz parte do meu portfólio de desenvolvimento web. O objetivo foi criar uma interface intuitiva, utilizando boas práticas de HTML5 e CSS3, garantindo que o design seja limpo e funcional.

## 🛠️ Tecnologias Utilizadas
As seguintes ferramentas foram usadas na construção do projeto:
* **HTML5** (Estruturação)
* **CSS3** (Estilização e Flexbox/Grid)
* **JavaScript** (Interatividade)
* **Google Fonts** (Tipografia)

## ✨ Funcionalidades
- [x] Landing page responsiva (Mobile/Desktop).
- [x] Página de login com validação básica.
- [x] Menu de navegação interativo.
